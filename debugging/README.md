# ChatGPT Introduction - Debugging & Automation

This repository is dedicated to the study of integrating Artificial Intelligence (ChatGPT) to enhance code quality, streamline debugging processes, and automate repetitive tasks within the Holberton School IT curriculum.

## Project Structure

* **debugging/**: Contains sub-projects where AI is used to diagnose, analyze, and fix logical bugs in various programming languages.
    * `factorial.py`: Fixed an infinite loop issue by ensuring the loop control variable decreases on each iteration.

## Learning Objectives
* Understand the role of AI assistants in diagnostic debugging.
* Analyze runtime behaviors like infinite loops (`KeyboardInterrupt`).
* Apply structured automation workflows for script adjustments.
